# 揭阳市3日游攻略

## 🏙️ 城市简介
揭阳位于广东省东南部，是潮汕地区的重要城市，素有"海滨邹鲁"的美誉。作为潮汕文化的重要发源地之一，揭阳拥有1300多年的建城历史，是潮剧、潮乐、潮菜的重要传承地。最佳旅行时间为10月至次年4月，此时气候凉爽宜人，避开了夏季的炎热多雨。

## 🚗 交通指南
**到达方式：**
- 飞机：最近机场为揭阳潮汕国际机场，距市区约20公里
- 高铁：揭阳站、潮汕站均可到达，潮汕站车次更多
- 汽车：广东省内各市都有直达揭阳的长途客车

**市内交通：**
- 公交：覆盖主要景点，票价1-3元
- 出租车：起步价8元，建议使用滴滴等网约车
- 共享单车：市区内随处可见，适合短距离出行

## 📅 详细行程安排

### 第1天：古城文化探索
- **上午**：参观进贤门（明代古城门）→ 揭阳学宫（岭南地区最大孔庙）
- **下午**：游览榕江西湖公园 → 揭阳博物馆了解潮汕文化
- **晚上**：夜游榕江两岸灯光秀 → 中山路步行街逛街
- **推荐美食**：牛肉粿条、蚝烙

### 第2天：自然风光体验
- **上午**：前往黄满寨瀑布群（亚洲第一瀑）
- **下午**：游览京明温泉度假村，体验温泉
- **晚上**：返回市区，品尝地道潮汕菜
- **推荐美食**：潮汕牛肉火锅、砂锅粥

### 第3天：民俗文化深度游
- **上午**：参观阳美玉都（亚洲最大翡翠玉器加工基地）
- **下午**：体验潮汕工夫茶文化 → 购买特产
- **晚上**：观看潮剧表演（如有演出）
- **推荐美食**：潮汕卤鹅、粿汁
